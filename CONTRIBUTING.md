# Contributing

This project is developed in versioned milestones. Please keep the current version working before moving to the next milestone.

## Workflow

1. Start from a clean branch.
2. Implement the current version only.
3. Add tests for new behavior.
4. Run the relevant test suite.
5. Fix failures before committing.
6. Update documentation when the architecture changes.
7. Commit with a version-aware message and tag the release.

## Quality bar

- No unverified claims of passing tests
- No hardcoded secrets
- No placeholder functionality considered finished
- No broken deployments or incomplete features pushed to the main branch
